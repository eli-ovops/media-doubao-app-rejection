# Eli自媒体固定制作方法

版本：`ELI-FRED-PRODUCTION-20261016-v1`。用户已要求固化并在后续视频中默认调用。适用于Eli自媒体的新片、组件适配及返修；不约束无关项目，不新增制作、付费、外传或发布授权。当前具体要求优先。

## 统一入口与复用单位

新稿/素材到整片以`fred-remotion-output`为主入口；精确参考还原或指定局部实现按需调用`fred-remake`，文字动效按需读`body-text-motion-effects`。不要并行开启旧Deck/H3全流程或另一套矛盾风格。

后续约90%的动效、组件及制作方法选型优先考虑用户已购Fred体系。这是选型优先级，不是虚报采用率。先看准确参考及源码，再决定适配；复用深入到对象关系、动作顺序、几何和信息职责。允许为本期拆分、组合和重写已认可组件的场景动作，删去重复开场/收尾；字体、缓动、阴影、坐标、字幕等基础实现沿准确kit。每段注明实际来源和改动，不只挂一个参考编号。

## 新内容到整片

1. **核实输入。** 以当前用户/运营侧冻结稿、真实录音、字幕和原素材为输入。先核顺序、内容与时码，不把录制指导写进字幕；与脚本不符的实际台词、口误和事实缺口分别处理，不虚构实测结果。没有最终录音时按当前授权做到合适阶段，不用估时强撑整片。
2. **定义看懂的变化。** 每段写清可见对象、起态、动作、结果、可读窗口和交给下一段什么。先定观众要理解的关系，再按“对象＋动作”检索组件；真实录屏只保留解释所需的过程与结果。
3. **比较准确候选。** 按主Skill现有`componentPlan`和库门禁实际看候选视频/核心帧，核准确filename/card-key、素材、源码/kit和依赖。不能只选熟悉的两三个组件，也不能候选未看就做通用卡片后补引用。没有合适项先查动作变体或场景级适配，明确剩余缺口。
4. **适配本期场景。** 复用成熟动作并围绕本期口播cue编排，统一实际字体文件和文字职责；最长文字、真实媒体、适用字幕及品牌一起进入真实关键状态。人物按本期需要出现，可与全屏内容交替；不把“内容主导”理解为彻底去掉真人。先用一组连贯代表镜头内部检验质感，再扩展整片。
5. **实现对象交接。** 上一段实际末态由下一段继承，包括锚点、box、层级、缩放、媒体时间和镜头状态。路过点保持运动方向/速度协调，阅读点停稳；不每个分段重启缓动，不重复开壳、wipe或阴影。真实切镜按内容准确切，不强制所有场景变形衔接。
6. **完成整片并检查导出。** 内部可分块渲染，最终按任务交完整MP4、可恢复工程和当前播放入口。检查运动中间态、最大相交、扩容/换词、首尾及接缝；布局看整幅，字形/线条看最终导出原尺寸。技术检查、采样、连续看听与用户认可分别记录；有明确整片授权时不做几秒就停等确认。

以上记录在本期既有Manifest/制作单的`designContract`、`componentPlan`、`motionEvents`与交接资料，不另建重复状态源或逐步审批表。用户明确先看样片时遵守；已授权直出/自主完成时内部修正推进，不继承原作者私人审批身份。

## 减少这次已证实的返工

- **正式几何不取低清检测图直接放大。** 字形、曲线、箭头与阴影使用准确源组件/字体及原生质量；检测轮廓只是测量输入，不能把阶梯掩模当矢量成品。新内容优先可参数化路径，避免把单期逐帧描轮廓冒充通用组件。
- **一个统一时钟。** 全局原生帧、局部场景帧、内部媒体帧明确换算一次；检查短合成/Freeze是否截断，禁止接段就把媒体从零播放。素材内容切镜和新引入的时间跳变分别判断。
- **入场到落定共用连续几何。** 不让备用布局突然切换至测量布局；按首次可见、阅读、显隐和退出的真实cue检查明暗与尺寸。
- **字体取实际字形。** 使用准确文件/字重、等待加载、检查最长行及父层缩放；bbox相近不代表字形一致，系统fallback/合成粗体不算准确实现。
- **补全缺口如实披露。** 优先准确干净素材；隐藏背景近似恢复不得称原像素重建，不用空白块或糊化掩盖缺失输入。
- **局部修正保护认可基线。** 固定当前输入SHA，保留无变化场景与原声；只重渲受影响区间及必要相邻接缝，组合成新完整版本。原尺寸推翻缩小图疑点时撤回旧判断，不改正确实现。

## 忠实复刻与素材复用

逐帧测量、字体拟合和原生轮廓重建用于忠实复刻，不自动成为新原创片的默认制作方式。原片人物、实录、图片和组件预览能否沿用以本次具体授权为准；准确区间和烘焙动效/透视须单列。整片时长完整不等于全部从零制作，复用画面不计作独立重建能力，MAE/解码/音轨相同不推出99%视觉一致。
